
# 🎓 CampusConnect — Campus Placement Management Portal
CampusConnect is a full-stack Campus Placement Management System designed to simplify campus recruitment. It connects students and recruiters through a centralized platform for managing placement drives, job applications, and recruitment activities.

## ✨ Features
- 👩‍🎓 Student & Recruiter Authentication
- 📊 Dedicated Student and Recruiter Dashboards
- 💼 Placement Drive Management
- 📝 Job Application & Status Tracking
- 🏢 Company and Recruiter Management
- 🔐 Secure JWT-Based Authentication
- 🎨 Responsive UI with Light/Dark Theme

## 🛠️ Technologies Used
- **Frontend:** React.js, Vite, CSS
- **Backend:** Java, Spring Boot, Spring Security
- **Database:** PostgreSQL
- **Authentication:** JWT
- **Tools:** Git, GitHub, Postman, Google Antigravity (AI-Assisted Development)

## 💡 System Capabilities
The platform enables users to:
- Register and manage student and recruiter profiles
- Explore and apply for placement opportunities
- Create and manage placement drives
- Track and update application statuses
- Manage recruitment activities efficiently
